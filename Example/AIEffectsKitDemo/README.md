# AIEffectsKitDemo

This folder will host an Xcode project showcasing each AIEffectsKit component.

**Setup (when ready):**
1. Open Xcode → File → New → Project → iOS App (SwiftUI, Swift).
2. Save it here as `AIEffectsKitDemo.xcodeproj`.
3. Add the repo root as a local Swift Package dependency: `File → Add Package Dependencies → Add Local...` → select the repo root (two levels up from this folder).
4. `import AIEffectsKit` and go.
